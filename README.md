# Projet-Sante-Numerique-Nsi

Simulation de propagation d'agent patogènes dans une population. 

1ière partie :

Simulation dans laquelle des petits bonhommes ([leur trouver un nom]) qui vont avoir 2 phases : 
Une phase chez eux où ils ne font rien et où ils sont en contact avec toujours les mêmes [leur nom]. 
Une phase où ils vont explorer le reste de l'environment et où des chances de rentrer en contact avec des individus qui sont atteint d'une maladie. 

Ils peuvent :
Guérir au bout d'un moment ;
Mourir au bout d'un moment ;
Transmettre une maladie ;
...
etc

On étudie alors l'évolution de cette maladie.

2ième partie : 

On peut modifier différents paramètres de l'environment pour faire voir différentes évolutions
